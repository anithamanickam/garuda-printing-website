# Sri Garuda Printing Website

React + Vite responsive business website based on the supplied Sri Garuda Printing homepage concept.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Replace demo images

The site uses remote Unsplash demo images so it works immediately. Replace the image URLs in `src/data/*.js` with your own Sri Garuda photos when ready.

## Important contact settings

Update the WhatsApp number, phone number, email and address in:
`src/data/site.js`

Use the WhatsApp number in international format without `+`, spaces or dashes.
